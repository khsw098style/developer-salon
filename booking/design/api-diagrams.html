Web予約作成のシーケンス

sequenceDiagram
    participant C as 顧客(ブラウザ)
    participant API as Edge Function
    participant DB as PostgreSQL(Supabase)

    C->>API: GET /menus
    API->>DB: select * from menus where is_active
    DB-->>API: メニュー一覧
    API-->>C: 200 menus[]

    C->>API: GET /availability?date&menu_id
    API->>DB: business_days / staff_shifts / reservations を集計
    DB-->>API: 空き枠候補
    API-->>C: 200 slots[]

    C->>API: POST /reservations (customer, menu_id, start_at)
    API->>API: 入力バリデーション
    API->>DB: 空き枠の再検証(サーバー側で再計算)
    alt 枠が埋まっていた
        API-->>C: 409 SLOT_UNAVAILABLE
    else 空きあり
        API->>DB: customers を電話番号でUPSERT
        API->>DB: insert into reservations(status='confirmed', source='web')
        alt EXCLUDE制約違反(競合)
            DB-->>API: 23P01 error
            API-->>C: 409 SLOT_UNAVAILABLE
        else 成功
            DB-->>API: reservation_number 等
            API-->>C: 201 予約完了
        end
    end
